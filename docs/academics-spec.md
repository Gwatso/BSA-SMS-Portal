## 2. Rules decided by the owner

| Rule | Decision |
|---|---|
| Subject pass | **50 % and above**: ZJC grades 1–6, O Level A–C |
| Overall result | **Pass** when the learner passes **5 or more subjects** (any subjects); otherwise Fail |
| Mark that decides position, subjects passed and result | **Exam mark**; the term mark is shown for information |
| Class position | Rank by the average exam mark over the subjects recorded; equal averages share a position (1, 2, 2, 4) |
| Fees | USD 250 per term covers everything; Levy, G.P.F. and Other are not charged separately |

## 4. Class register (one per form/stream)

Pupil details (left-hand pages), class numbers 1–55: Surname (block capitals), First
name (block capitals), Date of birth, Birth certificate number, Religion,
Boarder/Day scholar, Games house, Parent/guardian name, contact phone and residential
address.

Attendance (right-hand pages): "Register of attendance for the … term", weeks ending
Friday, a mark for each of Monday–Friday and a weekly total per pupil. Below each week:
Number absent, Actual attendance, Possible attendances, Weekly total of actual
attendances.

Fees pages: Term 1–3 × Tuition fees, Levy, G.P.F., Other (BSA charges one USD 250 fee per
term; see §2).

Regular check of register: for each of up to 13 weeks per term, the date and signature
of the head/deputy who checked it.

Attendance summary (per year): First/Second/Third term and total for the year, split
Day/Boarder × Boy/Girl; number of school days; average daily attendance = total number
of attendances ÷ number of school days; teacher's name and signature; school
head/deputy/T.I.C signature.

## 5. How the portal provides this

| Need | Where |
|---|---|
| Term dates (start/end of Terms 1–3, next term start) | BSA "School Terms" screen (administrators) |
| Daily attendance | Weblizar attendance (class teacher), statuses Present / Absent / Late / Holiday |
| Weekly register view, totals, possible attendances | BSA "Class Register" screen, mirroring the paper layout |
| Head's weekly check | BSA "Class Register": the head/deputy records the check (name, date) per week |
| Term/year attendance summary (Day/Boarder × Boy/Girl, average daily attendance) | BSA "Class Register" summary |
| Boarder/Day scholar | Weblizar "Student type" (renamed Day Scholar / Boarder) |
| Marks (term, exam, projects), subject remarks, initials | BSA marks entry, by subject teacher |
| Form teacher and principal comments, conduct | BSA report card screen |
| Report card | BSA printable report card in the book's layout, one per learner, A4 |

Counting rules: Present and Late count as attended; Absent does not; Holiday days and
days with no register taken are not possible attendances.
